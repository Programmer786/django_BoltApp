{% comment %} Adds left/right scroll buttons to any horizontally scrollable table. Works with all three table setups in this project: - plain .table-responsive wrappers - bootstrap-table (data-toggle="table"), which builds its own scroll container at runtime, so we re-scan after it initialises - wide tables with no scroll container at all (their parent gets one) Opt out by putting data-no-table-scroll on the table or any ancestor. {% endcomment %}
